
# AIML Assignment Practical 5

## Title
Demonstration of Basic Python Libraries

## Problem Statement
Demonstrate the use of Math, NumPy, SciPy, Pandas, and
Matplotlib for implementation on a dataset.

## Objective
To perform mathematical calculations, statistical analysis,
data preprocessing, and data visualization using Python libraries.

## Libraries Used
- Math: Mathematical functions such as square root and factorial.
- NumPy: Arrays and statistical calculations.
- SciPy: Statistical analysis, mode, and correlation.
- Pandas: Dataset handling, cleaning, and summary statistics.
- Matplotlib: Charts and data visualization.
- Seaborn: Correlation heatmap visualization.

## Dataset
A sample student performance dataset containing Maths,
Science, and English marks for eight students.

## Features
- Mathematical calculations
- NumPy array operations
- Dataset inspection and preprocessing
- Missing-value and duplicate checks
- Mean, median, and standard deviation
- Mode and correlation analysis
- Bar chart, line chart, and correlation heatmap

## How to Run
Install the required libraries:

pip install numpy scipy pandas matplotlib seaborn

Run the program:

python aiml_practical_5.py

## Output Files
- average_marks.png
- subject_marks.png
- correlation_heatmap.png

## Conclusion
This practical demonstrates how Python libraries simplify
scientific calculations, data analysis, preprocessing,
and visualization.
